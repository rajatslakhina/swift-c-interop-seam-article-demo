Empty on purpose. The Simulator run did not happen in the cycle that produced this repo: the session
runs unattended and macOS screen-control access cannot be approved during a scheduled run, so Xcode was
never opened. See "Verification status" in the top-level README.

Nothing here is a placeholder, a stock image, or a diagram relabelled as a device capture. When a real
run produces real captures, they go here.

Everything the library claims is pinned by `swift test` (16 tests), which needs no Xcode.
